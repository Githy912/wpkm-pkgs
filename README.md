# Read this place
This is the place for all of the packages for **wpkm** or **Windows Package Manager**

If you are uploading a package, make sure the binary is smaller than 100MiB or else PR will reject it!

### What is WPKM?

> WPKM also known as Windows Package Manager, is a package manager for Windows 10 or later that is made in Go and focuses on pushing package speeds and more.

It is under the **GNU GPL License v3.0** which is recommended for developers like you and me!

Why WPKM?

> It focuses on speed.
> It also focuses on ease of use.

Know more by downloading it!
